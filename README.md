# Grocery Store Database

This is a simple MySQL project for managing grocery store data.

## About Project
This project contains two tables:
- Products
- Suppliers

## Features
- Create database
- Create products and suppliers tables
- Insert product details
- Insert supplier details
- View records using SELECT queries

## Technologies Used
- MySQL
- SQL

## How to Run
1. Open MySQL Workbench.
2. Open the `groceries store.sql` file.
3. Execute the SQL script.
4. Run the following queries:

```sql
SELECT * FROM products;
SELECT * FROM suppliers;
```
